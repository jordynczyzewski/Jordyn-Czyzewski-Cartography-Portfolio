Madison Libraries and Youth

A spatial analysis exploring youth access to public library resources in Madison, Wisconsin.

Click on the image to view the StoryMap!

Madison Libraries and Youth is an interactive StoryMap created in ArcGIS Online that examines the spatial relationship between public library locations, youth populations, and access to educational resources across Madison.

The project analyzes proximity between schools and libraries, identifies potential library access gaps, and highlights how Madison Public Libraries services youth access. .

This work emphasizes the role of public libraries as critical community infrastructure and explores how spatial analysis can support more equitable planning decisions for youth-focused services.
